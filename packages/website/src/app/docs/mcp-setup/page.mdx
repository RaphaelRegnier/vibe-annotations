# MCP Setup

Start the updated server, then rerun the wizard to migrate old HTTP-only configurations:

```bash
vibe-annotations-server init
vibe-annotations-server token
```

Open the extension's **Options** page from Chrome's extension menu or chrome://extensions and paste the pairing token there. Pair again after restarting Chrome. Never paste the token into a website or save it in project configuration.

The wizard configures each supported agent with a local stdio proxy. The proxy reads the private token file and authenticates to the running HTTP server; agent configs contain no secret.

## Claude Code

```bash
claude mcp add --scope user --transport stdio vibe-annotations -- vibe-annotations-server mcp
```

## Cursor, Windsurf and OpenClaw

Use this entry under your agent's `mcpServers` key:

```json
{ "vibe-annotations": { "command": "vibe-annotations-server", "args": ["mcp"] } }
```

## Codex

Add to `~/.codex/config.toml`:

```toml
[mcp_servers.vibe-annotations]
command = "vibe-annotations-server"
args = ["mcp"]
```

## VS Code

In your MCP configuration:

```json
{ "servers": { "vibe-annotations": { "type": "stdio", "command": "vibe-annotations-server", "args": ["mcp"] } } }
```

## OpenCode

```json
{ "mcp": { "vibe-annotations": { "type": "local", "command": ["vibe-annotations-server", "mcp"] } } }
```

The server listens only on `127.0.0.1:3846` and checks Host, Origin and bearer authentication. All data endpoints, including legacy SSE, require authentication. For an unpacked extension, set `VIBE_ANNOTATIONS_EXTENSION_ID` to its exact ID before starting the server. Cross-host or WSL setups require an explicitly secured tunnel.

## MCP Tools

The server exposes these tools to connected agents:

| Tool | Description |
|------|-------------|
| `read_annotations` | Retrieve pending annotations with URL filtering and pagination |
| `watch_annotations` | Long-poll for new annotations (watch mode loops) |
| `delete_annotation` | Remove an annotation after implementing the fix |
| `delete_project_annotations` | Batch delete all annotations for a project URL |
| `get_project_context` | Infer framework and tech stack from a localhost URL |
| `get_annotation_screenshot` | Get screenshot data for visual context |

## SSE Transport (legacy)

Legacy `/sse` and `/messages` endpoints remain available to clients that explicitly send the pairing token in an Authorization header. The stdio configurations above use the authenticated HTTP proxy and need no endpoint substitution.
