# Annotating with Agents

The unauthenticated `window.__vibeAnnotations` page API has been removed. It allowed any script on an enabled website, including third-party scripts, to create, read, export or delete feedback.

Create feedback through the extension UI, then let your coding agent read and resolve it through the authenticated [MCP connection](/docs/mcp-setup). Manual copy/paste also works without a server.

Browser automation through a page JavaScript API is no longer supported. A future replacement needs a trusted extension channel and explicit user approval; enabling website access alone must never authorize website scripts to submit agent instructions.
