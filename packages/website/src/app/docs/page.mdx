# Documentation

Vibe Annotations is a visual feedback tool for web development. Annotate elements on your localhost pages, make design tweaks, and share structured feedback with AI coding agents or teammates.

## How it works

1. **Install** the [browser extension](https://chromewebstore.google.com/detail/gkofobaeeepjopdpahbicefmljcmpeof) and optionally the [MCP server](https://www.npmjs.com/package/vibe-annotations-server).
2. **Annotate** elements on any localhost page — add comments, tweak CSS, edit text.
3. **Share** via copy/paste, export, or MCP. AI agents read your annotations and implement the changes.

## Quick start

**Using Claude Code?** One command sets up everything: the server starts on its own, new annotations show above your prompt, and **Send to Claude** in the browser hands them over in one click.

```bash
claude plugin install vibe-annotations --marketplace RaphaelRegnier/vibe-annotations
```

See [Claude Code mod](/docs/claude-code).

The extension also works standalone with copy/paste. For MCP integration with any agent (auto-sync, watch mode), run the setup wizard:

```bash
npx vibe-annotations-server init
```

Installs the server, starts it, and configures your AI agent in one step. Prefer manual? See [Installation](/docs/installation) or [MCP Setup](/docs/mcp-setup).
